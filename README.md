# Digital Twin Portfolio

This repo is a starting point for a RAG application that answers questions about portfolio content, project notes, and work history.

## Contents

- `src/`: API, retrieval, ingestion, cache, and database modules
- `docs/`: architecture, setup, roadmap, and deployment notes
- `docker-compose.yml`: local service setup

## Status

The repo is partly implemented. Some pieces are working, while others are still scaffolding or planning material.

## Getting Started

Use [docs/GETTING-STARTED.md](docs/GETTING-STARTED.md) for setup.
